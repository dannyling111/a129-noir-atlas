# 5.3 材质与配色契约

## 目标与不可回归边界

同一套三维人物、镜头和场景允许即时切换清爽彩色和纯净黑白。新增正常表面纹理，但不恢复此前明确删除的照片/胶片/纸张效果。保持成人比例骨架、动作与飞行控制，保持十个场景、对白、短剧、录制回放和地面修复。

不得采用共面贴片、闪烁噪点、镜头抖动或关闭阴影来实现或掩盖材质。材质切换不能 loadScene，不能修改角色坐标，也不能重新生成纹理数据。

## 模块边界

- `materials.js`：配色 schema 与严格入口验证；8 层栅格贴图生成器；语义材质表；预设与安全存储读取。
- `renderer.js`：共享同一几何和阴影 passes。`render(objects,camera,scene,settings,time,look)` 的 look 缺省仍为旧黑白，应用层显式传入当前配色。
- `worlds.js`：构建时标记材质，批次键加入 finish，防止不同材质被错误合批。不改变 ground partition 或导航网格。
- `figure.js`：仅衣服增加织物材质及局部映射，不改变身体骨架。
- `look-ui.js` / `look.css`：现有页眉中的两模式按钮和可关闭的调色板；不增加中部常驻操作区。
- `director.js`：可选帧级 look 数据；手动配色覆盖回放优先。

## 纹理与光照

原始素材为 8×256×256×4 字节，完整 mip 链 9 层。R 通道为亮度/高度，G 为粗糙度。静态场景三平面映射基于世界坐标，服饰局部映射基于人物部件坐标。纹理梯度在分支与周期包裹前计算，通过 textureGrad 显式采样；支持时使用最多 4×各向异性过滤。贴图一次生成，冻结帧不随时间改种子。

材质强度为 0 时关闭表面采样影响；黑白分支完全绕过材质着色逻辑。色彩模式使用柔和环境光、方向光/射灯、原有真实阴影和有限粗糙度高光，不宣称物理路径追踪或全 PBR。

## 配色数据

```json
{
  "schema": "noir-atlas-look/1",
  "look": {
    "mode": "color",
    "palette": "natural",
    "saturation": 1,
    "texture": 0.58,
    "gloss": 0.25,
    "keepAccents": true,
    "colours": {
      "wall": "#ece9df", "stone": "#bfc5bd", "wood": "#bd9b70",
      "roof": "#536b6c", "foliage": "#517750", "water": "#74b8bb", "trim": "#8b5540"
    }
  }
}
```

只有 schema、模式、预设名、有限数值和七个合法六位 HEX 色合法时导入。文件限制 16 KB。归一化只输出允许的字段，不执行脚本、不使用数据作为远程 URL。

本地存储键 `noir-atlas.look.v1`；拒绝存储不应阻止启动、切色、渲染或导出。首次默认自然彩色；旧版的 cleanRenderSettings 不承担新材质设置。

## 必须验证

真实 WebGL 像素：颜色切换不只是 UI 状态；彩色→黑白→彩色冻结画面一致；严格黑白没有彩色像素；饱和度零的环境无残留蓝色光照；纹理强度零与有纹理输出不同；贴图八层不同且 mip 链完整；冻结输出不闪动。

状态：角色/镜头/场景/对白不变；剧本不中断；录制及手动覆盖兼容；真实控件的预设、颜色输入、导出/导入、手机点击可以操作。

几何：办公楼和庭院 partition 仍无重叠及重复顶面；包含旧版负对照的 72 组地面诊断继续通过；阴影矩阵不受镜头旋转缩放影响。

测试结果并非视觉品质、物理正确性或全部 GPU 上零伪影的数学证明。真机性能和可听语音另行验收。
