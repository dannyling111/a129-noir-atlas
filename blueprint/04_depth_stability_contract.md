# 地面深度稳定性契约 · 5.2

1. 办公楼和庭院地面，同一个 x/z 不允许有两个朝上可见的顶面。道路与房间用共享边界分区，不使用共面贴片或毫厘偏移。
2. 底座保留侧面与底面，不另画被地面覆盖的顶面。池塘在分区中明确开口。
3. 方向光阴影矩阵与场景/灯光有关，不随摄像机缩放或绕转重采样。阴影仍正常作用于建筑和人物。
4. 深度 texture 的 sampler 明确使用 highp；不允许仅设置 float highp 后误认为采样也一定高精度。
5. 不得用全画面模糊、噪点、禁用阴影、禁止旋转等方式绕过失败。
6. 验收必须包含旧版 HTML 负对照、真实 GPU 帧缓冲材质检查、全场景旋转、原有行为回归。不能只检查“没有 JavaScript 错误”。
7. 脚本见 tests/test_depth_stability.py；样本与失败阈值写在脚本和 TEST_REPORT.md 中。真机边界必须保留。
