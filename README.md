## 🏙 城市模式(新)

顶上点「**城市**」——这个 3D 世界变成一个**城市模拟游戏**:底下出现你的状态条和一排**决策卡**,
每张卡在你点之前就写着后果(`💰+210 ⚡−34 😖−24 专业+1.6`),点一下人物真的走过去做那件事,
时间推进,数字当场变。反复做,专业/认知/社交力/健康四条能力会一天天往上顶。

不是文字游戏:没有对话框、没有旁白,全部在界面上直接操作。

**里面那套逻辑**(照《NPC 社会模拟引擎研究与设计》选定的那一档做):
- 需求随时间流逝(饱腹/精力/社交/娱乐/自主/胜任/安全),缺口**非线性放大** —— 快饿坏时吃饭的价值远高于刚吃饱时
- 做什么由**连续效用 + 概率选择(softmax)**决定,不是固定日程轮流;
  τ = 5.5 + 2×压力/100,压力越大选择越乱
- **硬执行约束先于打分**:没雇主不能上班、没现金不能吃饭 —— 这类动作**连候选都进不去**,并直接写出原因
- **生理自保**会覆盖一般选择:饿到 5 分时不再随机挑,直接去吃
- **资金守恒**:净资产 = 现金 + 投资 − 债务;买投资只是现金转投资,不记为消费;
  现金不够付日常开销转成债务,不许出现负现金。跑 200 步之后账差 < 1e-6(有回归测试真算)
- **事故率按每小时算**(p = 1 − exp(−λΔt)),所以把页面调快**不会**提高每个模拟日的出事概率
- NPC 用**同一套**决策核 —— 所以尽责性高的人更常伏案,开放性高的人更常跑去看画

🔴 诚实边界:上面的**具体数值**(每步消耗多少、工作赚多少)是**显式游戏设定**,
没有用真人纵向数据校准过;有文献支持的只是"用连续需求、人格与价值来建模"这个思路本身。

```sh
node tests/sim_check.mjs    # 内核 15 项(含 2 条变红证明)
node tests/city_play.mjs    # 真手机 390×844 + 真 touch 18 项
```

## 5.4.3 画面让路

手机端去掉第二排按钮（镜头台 / 跟随 / 特写默认收起），对白框缩小并贴在说话人旁边，不再顶到最上沿挡住别人的名字。三维缩放、透视/正交收到右下角「镜头」里，平时不占画面。

## 怎么玩

点地行走；拖空白旋转；双指缩放；左下摇杆移动。页眉可切 **黑白 / 彩色 / 配色**。点「角色」换人换装；点「更多动作」打开动作库。
