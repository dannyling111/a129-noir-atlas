# NOIR ATLAS 5.3 · 清爽彩色 / 纯净黑白

A129 独立仓库网页：十个真实 3D 场景、自由镜头、清爽彩色贴图与纯净黑白随时切换。

## 线上地址

- 首页：https://dannyling111.github.io/a129-noir-atlas/
- 仓库：https://github.com/dannyling111/a129-noir-atlas

纯静态单文件，无 CDN、无外部模型。用支持 WebGL2 的浏览器打开即可。

## 怎么玩

点地行走；拖空白旋转；滚轮或双指缩放；左下摇杆移动。页眉可切 **黑白 / 彩色 / 配色**。

## 本地

打开 `index.html`，或：

```sh
python3 -m http.server 8080
```

源码在 `src/`，`python build.py` 可重新打包单文件。

这是 5.3 验收版。证据截图未纳入本仓库，以免把网页仓库撑大。
